# Screenshot notes

The PNG files in this folder are **static UI preview screenshots** generated from the bundled fictional demo-candidate analysis. They illustrate the intended HireSense AI screens: overview, ranking, analytics, candidate insights and methodology.

They are not screenshots of a live Streamlit browser session. The build environment used to prepare this ZIP did not have Streamlit installed and could not download packages because outbound package-network access was unavailable. The Python source was syntax-compiled and the core logic tests were run successfully. To capture live application screenshots on your computer, install `requirements.txt`, run `streamlit run app.py`, enable demo candidates and click **Analyze candidates**.
